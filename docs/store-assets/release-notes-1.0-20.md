# Release notes — Mirrolit 1.0 (versionCode 20), closed testing

## Play Console → "What's new" (en-US, 82 chars)

```
Better book-language detection, and you can now choose the book's language yourself.
```

## Note for testers

**Mirrolit 1.0 (20) — what to try**

1. Open books in different languages (Spanish, Japanese, German, Chinese…): the language button
   at the top shows the right language, e.g. "ES → RU".
2. Tap the language button: the "From" tab shows what was detected. If it's wrong, pick the
   book's language; Mirrolit remembers it for that book. "Automatic" goes back to detection.
3. Open a book in a language Mirrolit can't translate yet (Finnish, Latin, Danish…): it reads as
   one column with a "Not translated" note instead of a garbled translation.
4. Try Offline HQ as the translator for these books.
