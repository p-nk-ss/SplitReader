# Release notes — Mirrolit 1.0 (versionCode 14), internal testing

## Play Console → "What's new" (en-US, 56 chars)

```
Pictures in books now show at full size instead of tiny.
```

## Note for internal testers

**Mirrolit 1.0 (14) — what to try**

Open an illustrated book (e.g. Gutenberg's illustrated "Alice"): plates now show at their proper
size, up to the page width, and a tall plate fits on one screen. Tap to show the bars — the
pictures and text stay put.
