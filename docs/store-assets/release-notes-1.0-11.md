# Release notes — Mirrolit 1.0 (versionCode 11), internal testing

## Play Console → "What's new" (en-US, 83 chars)

```
Fixed: 100% at the end of a book, and the divider handle no longer covers pictures.
```

## Note for internal testers

**Mirrolit 1.0 (11) — what to try**

1. If you have version 10 from Play: a banner at the top of the Library offers this update —
   try Update, then Restart.
2. Read to the very end of a book: the bottom bar now shows 100%, like the Library.
3. In the side-by-side layout, scroll past an illustration or a chapter title: the small handle
   on the divider fades out instead of covering them.
