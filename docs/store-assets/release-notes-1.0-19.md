# Release notes — Mirrolit 1.0 (versionCode 19), closed testing

## Play Console → "What's new" (en-US, 74 chars)

```
Tablet fixes: nothing hides under the taskbar; smoother first book import.
```

## Note for testers

**Mirrolit 1.0 (19) — what to try**

1. On a tablet with a taskbar at the bottom (Samsung, Lenovo, Pixel Tablet): the account button at the
   bottom of the left menu is fully visible, and the end of every screen stays above the taskbar.
2. Add a book to an empty library: the screen goes straight from loading to the book, without flashing
   "Your library is empty" first.
3. Open a book from the start while its translation is being prepared: the banner no longer covers the
   chapter number.
