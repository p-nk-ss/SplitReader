# Release notes — Mirrolit 1.0 (versionCode 32), closed testing

## Play Console → "What's new" (en-US)

```
Better offline translation: Offline HQ and ML Kit no longer drop parts of long sentences, and "Mrs." or "Mr." no longer break a sentence in two. The translator menu now shows our quality rating for each free translator.
```

## Note for testers

**Mirrolit 1.0 (32) — what to try**

1. Open an English classic (for example Pride and Prejudice) with Offline HQ and read a few pages
   with long sentences. The translation should keep every clause; names after "Mr." and "Mrs."
   stay in the same sentence.
2. Paragraphs of medium length that you have already read are translated once more the first time
   you see them after the update (the saved translation is refreshed). After that they come from
   the saved copy as before.
3. Open the translator menu (the translator button in the reader). Each free translator shows
   stars with "OUR RATING": Quick Translate 4, Offline HQ 2.5, ML Kit 1.5. This is our own
   comparison over 18 languages, not user reviews. Translators with your own API key show none.
