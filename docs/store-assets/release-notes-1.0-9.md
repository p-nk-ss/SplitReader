# Release notes — Mirrolit 1.0 (versionCode 9), internal testing

## Play Console → "What's new" (en-US, 95 chars)

```
Fixed: illustrations in many classic books now appear inside chapters instead of going missing.
```

## Note for internal testers

**Mirrolit 1.0 (9) — what to try**

1. Open an illustrated classic (e.g. Gutenberg's illustrated "Alice"): the plates now show inside
   the chapters. Chapter numbers and your saved place are the same as before.
2. Books whose first page is only a cover image no longer repeat the cover at the start.
3. A book made only of pictures now opens and shows them.
