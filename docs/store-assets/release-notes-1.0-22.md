# Release notes — Mirrolit 1.0 (versionCode 22), closed testing

## Play Console → "What's new" (en-US)

```
Plays and verse set in tables now open. Clearer messages, and smaller fixes.
```

## Note for testers

**Mirrolit 1.0 (22) — what to try**

1. Open a play or poem whose text is laid out in a table (e.g. Čapek's "R.U.R." in Czech, the
   Greek "Iliad" from Project Gutenberg): it now reads line by line instead of opening empty.
2. If a book's file has been moved or deleted, tapping it in the Library now says so instead of
   doing nothing.
3. Tap anywhere on the "Continue reading" card to open the book.
4. In a paragraph in another language, Listen reads the word in that language, and the word popup
   explains why a paragraph isn't translated.
5. Almanac shows "Unknown" instead of "UND" for books whose language wasn't detected.
