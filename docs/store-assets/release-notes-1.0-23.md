# Release notes — Mirrolit 1.0 (versionCode 23), closed testing

## Play Console → "What's new" (en-US)

```
Offline HQ — the better on-device translator — is now the default.
```

## Note for testers

**Mirrolit 1.0 (23) — what to try**

1. If you never picked a translator, books now translate with Offline HQ. The first book in a
   new language downloads its language pack (about 35 MB) — the banner shows the progress.
2. If you chose a translator yourself (ML Kit, DeepL…), nothing changes.
3. On tablets, the "ML KIT READY" label in the top corner is gone.
