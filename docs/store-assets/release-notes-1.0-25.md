# Release notes — Mirrolit 1.0 (versionCode 25), closed testing

## Play Console → "What's new" (en-US)

```
Classic books no longer show their printed table of contents or list of illustrations as text (no more stray "PAGE").
```

## Note for testers

**Mirrolit 1.0 (25) — what to try**

1. Open Project Gutenberg's illustrated "Alice's Adventures in Wonderland" (from the catalog or a
   file): the opening pages show the title and pictures without "PAGE", "To face page" or the
   chapter list as paragraphs to translate.
2. Plays and verse set as tables (Čapek's "R.U.R." in Czech, the Greek "Iliad") still open line by
   line, as fast as before.
