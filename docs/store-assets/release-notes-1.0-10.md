# Release notes — Mirrolit 1.0 (versionCode 10), internal testing

## Play Console → "What's new" (en-US, 83 chars)

```
New: Mirrolit now tells you when an update is available and installs it in the app.
```

## Note for internal testers

**Mirrolit 1.0 (10) — what to try**

Install this version from Play first. When the next version comes out, a banner appears at the top
of the Library: "A new version of Mirrolit is available" with **Update** / **Not now**. Update
downloads in the background, then **Restart** installs it. "Not now" hides the banner for 3 days;
Settings → About still shows the update.
